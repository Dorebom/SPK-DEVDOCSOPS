# 17開発工程・作業種別・成果物・判断ゲート

## 1. 正式な分類軸として使う17工程
工程名と主な内容はユーザー指定をそのまま採用する。以下のP番号、成果例、適用確認の仕組みは今回の設計案であり、未実施作業を完了扱いしない。

| phase_id | 開発フェーズ（ユーザー指定） | 主な内容（ユーザー指定） | 追跡する成果例（今回の案） |
|---|---|---|---|
| P01 | 企画・構想 | 課題定義、目的、対象ユーザー、事業要求、開発範囲 | 企画意図・対象・成功条件・範囲 |
| P02 | 要求分析 | ユーザー要求、ステークホルダー要求、ユースケース、制約整理 | 利用者要求・UC・制約と原資料 |
| P03 | 要求仕様策定 | 機能要求、非機能要求、外部仕様、受入条件 | 要求／USDM・仕様・受入条件と版 |
| P04 | システム設計 | システム構成、責務分割、HW/SW分割、インターフェース | システム構成・HW/SW配賦・境界IF |

## 2. 工程と作業種別を分離する
phase_idsは上表、activity_typeはENGINEERING／RESEARCH／MEETING／REVIEW／PROJECT_MANAGEMENT／PROCUREMENT／REWORK／PROCESS_IMPROVEMENT等。調査・会議・リスク分析・工数集計を第18工程として付け足さず、関連する工程と対象Traceへ対応付ける。全工程にまたがる定常作業はCROSS_PHASEとして対象工程を明示する。工程未確定はUNASSIGNEDとして解消する。

TASKのDISCRETE／LOEは成果進捗の算定区分であり、会議＝必ずLOEではない。具体的な設計判断を完成させる会議TASKはDISCRETE、期間内の定常運営はLOEとしてよい。

## 3. 実行順・反復・並行
17行は追跡範囲を分類したもので、ウォーターフォールの一回通過や一列依存を義務付けない。単体・結合・非機能のテスト設計をP03〜P07と並行して準備できる。同じ成果に複数phase_idsを付けても、工数を重複集計しない。

P13のValidationはユーザー目的・製品要求の成立を確認する。P11の要求仕様への適合と区別し、双方の根拠へリンクする。P14の準備判定とP15の実導入、P16の障害対応とP17の改善採否も別の成果である。

## 4. 工程ごとの適用計画
各Traceのphase_planは17件を持ち、APPLICABLE／NOT_APPLICABLE／TBDを記録する。小変更・特定調査では全工程を実施する必要はないが、対象外の理由・影響評価・決定証拠を持つ。未定を対象外へ変換しない。

特定工程で要求する成果kindの例：P09〜P12はTEST_CASEとTEST_RESULT、P15はRELEASEとDEPLOYMENT。実際の必須成果は案件の受入条件で決定する。レビュー済みのリンク数や17工程への記録件数を、そのまま工程完了率にしない。

## 5. 判断ゲートと工程は別の軸
R10のG0〜G4は提案ゲートとして維持し、P01〜P17へ番号を機械対応させない。承認者・入出力・対象版・必要証拠をゲートごとに決める。要求・仕様採用、タスク着手、作業完了、文書Baseline公開、製品リリース、認証判断、発注・支出は別承認。

## 6. 旧R10 phaseとの対応候補
| 旧phase | 新しい候補 | 自動処理の扱い |
|---|---|---|
| DISCOVERY | P01/P02、又は対象工程＋RESEARCH | 文脈確認が必要 |
| REQUIREMENTS | P02/P03 | 要求分析と仕様策定を確認 |
| SPECIFICATION | P03 | 既存記述の内容を確認 |
| ARCHITECTURE | P04/P05 | システム設計との責務を確認 |
| DESIGN | P06/P07、テスト設計ならP09〜P12等 | 分割又は複数工程化を判断 |
| IMPLEMENTATION | P08 | 対象TASKで確認 |
| VERIFICATION | P09/P10/P11/P12 | 試験粒度・品質を確認 |
| VALIDATION | P13 | 利用目的との対応を確認 |
| RELEASE | P14/P15 | 準備・実導入を区別 |
| OPERATIONS | P15/P16/P17等 | 導入・保守・改善を確認 |
| MANAGEMENT | 対象P番号＋PROJECT_MANAGEMENT/MEETING等 | 第18工程としない |

旧値は互換のため読めるが、移行済みとは判定しない。旧TASK・実績を黙って再採番しない。
