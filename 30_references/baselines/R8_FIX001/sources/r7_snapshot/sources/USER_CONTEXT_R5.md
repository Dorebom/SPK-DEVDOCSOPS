# CTX-R5 — 第2.1節のECHONET Lite接続明示

## ユーザー指示

> SPK-GW筐体内のH側内にあるECHONET Lite Controllerが空調・給湯・計測器などのECHONET Lite機器やPVや蓄電池クラスなどのPCSのECHONET Lite機器とどう接続しているのか、2.1 システムコンテキスト：共通宅内ルータを明示からは読み取れない。改修して。

## 改訂の位置付け

R4の接続構成・責任主体を変更せず、通常EL通信の端点・宅内LAN経路・意味的担当・応答と観測の戻りを明示する。全体図の省略線を解消し、接続拡大図・往復経路表・機械可読な通常EL経路台帳を追加する。

R4の「全出力制御サーバ通信は宅内ルータ経由」「EL接続PCSのみPCS自身がGW非経由で取得」「RS-485接続PCSはGW G側管理」を維持する。図の具体化は新しい規格・プロトコル・型式・数値・CPU・NIC・試験・認証判断の確定ではない。原典の役割名称と既存TBDを保持し、外部資料の新規調査は行わない。
