# 文書パッケージの品質確認

本ファイルは**文書とZIPの確認**について記録します。ソフトウェア・実機・認証の合格記録ではありません。

| 確認項目 | 結果・範囲 |
|---|---|
| UTF-8読戻し | 全Markdownを読戻し、置換文字なし |
| 相対リンク・明示アンカー | 統合版を含む164リンクをローカル検査。リンク先欠損なし |
| コードフェンス | 全Markdownで開始・終了の整合を確認 |
| JSON例 | 分割ノート内4例をJSONとして解析可能と確認。実機電文ではない |
| Mermaidソース | 分割ノート内14図。コードフェンス、図種、subgraph／sequenceブロック対応を静的確認 |
| Mermaidレンダリング | 未実施。完全なMermaidパーサや各ビューアでの表示確認は行っていない |
| 統合版 | 分割ノートから生成。リンクを内部アンカーへ変換 |
| チェックサム | MANIFEST_SHA256.txtに自己ファイルを除く各同梱ファイルのSHA-256を記録 |
| ZIP | 作成後に全エントリを読戻し、CRCとManifestのSHA-256を検証 |
| 公開資料 | 出典ノートの確認範囲のみ。原本PDFの再配布なし |
| 実装・POC・実機・JET試験 | すべて未実施。10_Requirements_Tests.mdは試験計画 |

## 文書としての判断境界

「ユーザー合意」「推奨設計」「公開資料」「TBD」を分離しています。特定機器の対応、CPU配置、JETの試験免除、全国一律の制御対象、機器側Leaseを未確認のまま確定仕様にはしていません。

文書の機械的確認は、技術判断の正しさや機器実装の適合を証明するものではありません。採用時には設計レビューと適用条件の確認が必要です。
