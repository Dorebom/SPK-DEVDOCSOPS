# CTX-R3 — 出力制御接続方式の選択要求

入力日：2026-10-06。ユーザーの明示要求：

> 出力制御サーバとの接続は、PCSに直接と、GWがスケジュールを取得・制御・管理して、PCSに指示するパターンの両方選べるようにして。

## 明示された変更

PCSが直接接続する方式と、GWがスケジュール取得・管理・制御を担当してPCSへ指示する方式を、製品システムの選択肢として扱う。R2の「案A優先、案Bは必要時の候補」という全体既定を、二方式の選択仕様へ改める。

## 明示されていない事項／今回の設計具体化案

内部識別子PCS_DIRECT／GW_MANAGED、制御scope単位の選択、一つの有効なスケジュール適用主体、施工・保守時の管理切替、無条件自動フェイルオーバー非採用、表示項目、試験・台帳は本書の提案である。ユーザーは切替中の無停止、同一CPUでの独立性、全PCS対応、任意の量産機での切替、JET試験免除を承認したわけではない。

## 用語上の境界

GWは筐体・製品の意味。H側は通常HEMS・上位サービス・Web UI等の更新領域、G側は出力制御の必須責務・資源を管理する論理領域。GW_MANAGEDでGWがG側を持つことを許すが、H側を出力制御の必須処理へ統合しない。具体的CPU・OS・リセット・ドライバ配置は未確定。

新しい法律・規格・JET試験条件を追加調査・確定した改訂ではない。原典の引用・限界は保持する。
