# 原資料・受領版・出典

原本はここへ改変せず保存する。取り込み時はregisterで文書ID・業務上の版・SHA-256・対象を登録する。フォルダに置くだけで承認済み仕様にはならない。

同一原本・同一文書ID/版の再登録は同じsource_idを返す。改版・内容変更は別のsource_idで保存し、旧原本や既存仕様を削除しない。XML・数式・マクロ・外部リンクを実行しない。

原本ZIP1個とその読取り用展開一式を保持する。R1〜R7のZIPの再帰的な追加同梱は行わない。欠落・変換・不採用を区別して記録する。
