# 草案とprepare済み候補

DR-*等の作業ID直下へ、現行の5部44章と台帳の編集コピーを置く。PREP-*は生成・検査済み候補。どちらも正本ではない。メタデータ・マージ判断・承認要求は兄弟のanalysisへ置く。

深さを `20_work/drafts/<ID>` に固定すると、`10_canonical/releases/<Baseline>` への移動でも30_referencesへの相対参照が変わらない。IDの下にさらにspecフォルダを作らない。
